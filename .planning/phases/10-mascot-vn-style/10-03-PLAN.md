<objective>
Build the persistent VN-style `MascotStage` client component and its style tokens: a fixed CSS-gradient backdrop, a waist-up centered Coco sprite delivered via `next/image`, and an additive dialogue box with a "Coco" speaker-name label. The sprite is chosen by `deriveExpression()`; the speaking amplitude animation is driven by `updateSpeakingVisual()` inside a `requestAnimationFrame` loop that silently degrades via `shouldDegrade()` (or `prefers-reduced-motion`) to a static sprite.

Purpose: Deliver the on-screen 2D Coco (MASCOT-01/D-01), the fixed 4-sprite content-tied expression set (MASCOT-03/D-05, with `coco-sad-alpha.png` structurally excluded), the fixed single gradient backdrop (D-06), and the low-end-device degrade guardrail (MASCOT-04/D-07) — all as a decorative, non-blocking client component that composes the three Plan 01 pure helpers with no logic of its own.

Output: `src/components/student/styles.ts` extended with a `// ─── Phase 10: Mascot stage tokens ───` section, and a new `src/components/student/MascotStage.tsx`. Wiring into the shell is Plan 04.
</objective>
