## Decisions Made

- "Words to practice:" lead-in chosen to match the existing mission-flow `WordsToPractice` label idiom ("Words to practice — tap to hear:") minus tap-to-hear, which doesn't apply in the recap
- Heading contract asserts `Pronunciation</strong>` rather than the bare word, since `"Pronunciation"` alone trivially matches the `turn.pronunciation` prop name and would make the contract meaningless
- Hover/active rules use `!important` because the button's base background is set via the inline `style` attribute (spread of `primaryButtonStyle`), which otherwise wins over any stylesheet rule
- The hover styles use a plain `<style>` element (root-layout idiom), not runtime styled-jsx, avoiding the FOUC class of bugs eliminated earlier in this phase
