<objective>
Build the Phase 9 scoring engine (PRON-01): install the Azure Speech SDK + ffmpeg-static, add a server-only WAV-transcode utility, a server-only Azure pronunciation-assessment adapter following this codebase's injectable-client convention, and a pure score-to-star domain module that is the single source of truth for star thresholds and copy. No pipeline wiring, no UI, no DB writes in this plan — those are 09-04/09-05/09-06.

Purpose: PRON-01 requires scoring a spoken turn against the target sentence. This plan produces the three composable, independently-testable units (transcode, score, map) with injected fakes so automated verification never calls the paid Azure API — mirroring how `transcription.ts` isolates the paid OpenAI call. Isolating `scoreToStarBand` in one module is what lets the 09-05 calibration pass (D-04) tune thresholds without touching Azure call code.
Output: `src/server/audio/audio-transcode.ts`, `src/server/audio/pronunciation-scorer.ts`, `src/domain/pronunciation/scoring.ts`, and their three test files; two new npm dependencies.
</objective>
