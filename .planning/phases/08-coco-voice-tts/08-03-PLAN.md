<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student browser -> TTS route | Untrusted request selects a visible line descriptor. |
| TTS route -> Supabase service role | Server checks assignment ownership and cache rows. |
| TTS cache -> OpenAI | Paid provider call happens only on validated cache miss. |
| TTS cache -> Storage | Private generated audio object becomes a signed playback URL. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure / Elevation of Privilege | Server-only OpenAI usage | mitigate | `openai` import is confined to `src/server/audio/tts-generator.ts`; tests use fake clients. |
| T-08-02 | Denial of Service / Abuse | Arbitrary paid TTS generation | mitigate | Server resolves line text from owned assignment/profile state and rejects arbitrary text. |
| T-08-03 | Tampering | Cache-key tampering | mitigate | Server computes canonical content hash and ignores client-supplied hash attempts. |
| T-08-04 | Information Disclosure | Unauthorized assignment audio lookup | mitigate | Service-role lookup filters `assignment_students.id` and `student_id` before signed URL creation. |
| T-08-05 | Information Disclosure | Public/private Storage exposure | mitigate | Route returns private signed URLs from `tts-audio`; no public URL helper is used. |
| T-08-06 | Denial of Service | Provider failure blocking homework | mitigate | Provider/storage failures map to retryable route errors consumed by disabled/error speaker state. |
| T-08-07 | Information Disclosure / Elevation of Privilege | Client OpenAI imports | mitigate | Source-boundary tests from Plan 01 cover student modules after UI integration. |
| T-08-SC | Tampering | npm installs | accept | No package-manager install tasks in this plan. |
</threat_model>
