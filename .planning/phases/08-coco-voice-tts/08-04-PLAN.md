<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student component -> TTS route | Client sends only line descriptors for currently visible Coco lines. |
| Audio element -> signed URL | Browser plays private generated audio through app-issued signed URL. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure / Elevation of Privilege | Server-only OpenAI usage | mitigate | Client component imports only domain types and fetches the route; no provider SDK import. |
| T-08-02 | Denial of Service / Abuse | Arbitrary paid TTS generation | mitigate | UI sends bounded line descriptors, while server resolves text from owned state. |
| T-08-03 | Tampering | Cache-key tampering | mitigate | UI does not send content hashes. |
| T-08-04 | Information Disclosure | Unauthorized assignment audio lookup | mitigate | UI uses current assignmentStudentId; server remains the authorization boundary. |
| T-08-05 | Information Disclosure | Public/private Storage exposure | mitigate | UI consumes signed route result; no direct public Storage URL construction. |
| T-08-06 | Denial of Service | Provider failure blocking homework | mitigate | Component failure affects only the speaker control; text and recording remain available. |
| T-08-07 | Information Disclosure / Elevation of Privilege | Client OpenAI imports | mitigate | Vitest source-boundary spec checks student modules; Playwright remains reserved for browser/audio behavior. |
| T-08-SC | Tampering | npm installs | accept | No package-manager install tasks in this plan. |
</threat_model>
