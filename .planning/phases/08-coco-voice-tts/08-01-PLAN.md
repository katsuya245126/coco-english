<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student browser -> TTS route | Untrusted student client requests paid TTS metadata. |
| TTS route -> Supabase service role | Server-owned assignment and cache lookup bypass browser authorization. |
| TTS cache -> Supabase Storage | Generated audio object keys and signed URLs cross into Storage. |
| Server adapter -> OpenAI | Paid provider call with classroom-facing content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure / Elevation of Privilege | Client OpenAI boundary | mitigate | Tests forbid OpenAI/server-adapter imports from student client modules; production adapter is planned server-only. |
| T-08-02 | Denial of Service / Abuse | Arbitrary paid TTS generation | mitigate | Tests require server-resolved voice lines and provider call count checks before implementation. |
| T-08-03 | Tampering | Cache key construction | mitigate | Tests require server canonicalization and reject reliance on client-provided cache hashes. |
| T-08-04 | Information Disclosure | Assignment audio lookup | mitigate | Tests require assignment_students ownership filters before signed URL generation. |
| T-08-05 | Information Disclosure | TTS Storage exposure | mitigate | Plan set chooses private `tts-audio` bucket and tests signed URL route behavior. |
| T-08-06 | Denial of Service | Provider failure blocking homework | mitigate | Tests require provider failure to become a non-blocking speaker error state. |
| T-08-07 | Repudiation / Cost audit | Cache hit verification | mitigate | Tests require explicit miss/hit metadata and one provider call across duplicate requests. |
| T-08-SC | Tampering | npm installs | accept | No package-manager install tasks in Phase 8; existing dependencies are used. |
</threat_model>
