<objective>
Extend the teacher mission create/edit form with the three Coco Chat controls: the default-off "Dynamic conversation mode" toggle (D-06), the chat-mode-only "Turns to complete this mission" field (3-8, default 5, D-02), and the editable "Scene premise" textarea (D-07) — filled by a "Generate premise" action calling the standalone 11-03 adapter. Persist `conversation_mode`, `scene_premise`, and the chat-mode `required_turns` on save.

Purpose: This is the teacher's opt-in surface for CHAT-01 and the authoring surface for SCENE-01. It must respect the conditional-refine relaxation from 11-01 (chat missions save with zero authored turns) and the AI-degrades-gracefully rule (premise generation failure never blocks save).
Output: Extended MissionForm + a premise-only generate server action.

Replanning note (2026-07-15): This plan originally wired premise auto-fill through `MissionDraftPanel.tsx`'s "apply-draft" function, assuming the AI mission-draft feature was still live. That feature was deleted end-to-end in commit `582b8fcd` (~2026-07-12), before this plan (authored 2026-07-03) reached execution — `MissionDraftPanel.tsx` no longer exists. `MissionForm.tsx` today is a pure manual-entry form (title/targetPattern/topic/level/turns) with no AI-draft-apply step at all. Task 2 below drops all `MissionDraftPanel.tsx` references: the "Generate premise" button now calls 11-03's standalone `generateScenePremise` adapter directly (via the 11-05 Task 1 server action) and fills the textarea in `MissionForm.tsx` itself — there is no separate draft-apply path to extend.
</objective>
