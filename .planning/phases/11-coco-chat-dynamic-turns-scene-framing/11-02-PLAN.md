<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| student transcript → LLM | untrusted speech-to-text text reaches the generation prompt |
| student transcript / Coco line → OpenAI moderation | student/AI content sent to a distinct OpenAI API surface |
| generated Coco line → student (later, via 11-03) | untrusted generated output until moderated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-04 | Tampering / Elevation | prompt injection via student transcript | mitigate | Transcript passed as JSON data inside the user message, never concatenated into system instructions (mirrors existing adapters); student input moderated before the LLM sees it (wired in 11-03) |
| T-11-05 | Tampering | moderation fail-open on error/malformed response | mitigate | isContentSafe returns safe:false on throw/empty/non-boolean; property-style held-out test enforces it (Pitfall 3) |
| T-11-06 | Information Disclosure | excess student PII to OpenAI | mitigate | System prompt forbids student names/PINs/audio keys (verbatim convention from existing adapters); transcript is the only per-student content |
| T-11-07 | Tampering | conversation drift from stale steering | mitigate | Stateless per-turn reconstruction; no previous_response_id (CHAT-04, Pitfall 2) |
| T-11-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages (openai@6.45.0 already installed + audited Phase 6/8); no install task, no [ASSUMED]/[SUS] package |
</threat_model>
