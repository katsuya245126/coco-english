<objective>
Establish the additive database schema and domain-schema foundation for Coco Chat: the migration adding `missions.scene_premise`, `missions.conversation_mode`, `attempt_turns.coco_line`, and `attempt_turns.moderation_event`; the Zod schema changes on `missionFormSchema` and `missionSnapshotSchema` that make the `turns.length === requiredTurns` refine conditional on chat mode; and the assign-time snapshot builder capturing premise + mode for reproducible attempts.

Purpose: Every downstream plan (adapters, orchestration, UI) reads from these columns and schema fields. Getting the additive schema and the conditional refine right first (RESEARCH.md Pitfall 1) unblocks conversation-mode missions, which otherwise fail snapshot validation with zero authored turns.
Output: One additive migration (pushed live), extended domain schemas with a conditional refine, an updated snapshot builder, and regenerated DB types.
</objective>
