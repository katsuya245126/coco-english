<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> audio route | Untrusted FormData contains file, MIME type, duration, attemptId, turnOrder, and clipKind |
| audio route -> service-role Storage/DB | Service-role bypasses RLS and must enforce student ownership in app code |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Elevation of Privilege | audio upload | mitigate | Load `assignment_students` by id and `student_id = unlock.studentId` before Storage or DB write |
| T-05-05 | Tampering | clip metadata | mitigate | Server computes object key and byte size; validates clipKind/turnOrder/duration |
| T-05-06 | Information Disclosure | Storage bucket | mitigate | Private bucket, no public URLs, server-owned upload |
| T-05-07 | Repudiation | failed uploads | mitigate | `audio_clips.processing_status` records pending/uploaded/failed |

No high severity threat is left unmitigated.

**Schema push:** Required. This plan modifies `supabase/migrations/*.sql`; Task 2 is blocking and manual.
</threat_model>
