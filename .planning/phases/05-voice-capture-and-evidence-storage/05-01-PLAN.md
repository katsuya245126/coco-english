## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser microphone -> client component | Browser permission and raw audio capture are untrusted and can fail or be unsupported |
| recorded blob -> future upload route | Blob metadata is client supplied and must be revalidated in Plan 02 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | microphone permission | mitigate | Request microphone only after explicit button press; show clear permission state |
| T-05-02 | Denial of Service | long recordings | mitigate | Enforce `MAX_RECORDING_MS = 20000` in the recorder control |
| T-05-03 | Compatibility | unsupported mobile browser | mitigate | Feature-detect `getUserMedia` and `MediaRecorder`, show unsupported state |

No high severity threat is left unmitigated.

**Schema push:** Not required. This plan modifies client/domain code only.
