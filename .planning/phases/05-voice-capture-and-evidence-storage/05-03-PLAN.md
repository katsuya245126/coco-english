## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server -> OpenAI API | Audio leaves the app server for transcription |
| transcription result -> DB transcript fields | External text is stored and later shown to teachers/students |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-08 | Information Disclosure | OpenAI API key | mitigate | Key is server-only env var, never `NEXT_PUBLIC_`, never imported client-side |
| T-05-09 | Tampering | failed/empty transcription | mitigate | Empty/failure maps to failed status and retry; no fake transcript is written |
| T-05-10 | Repudiation | audio processing state | mitigate | `audio_clips.processing_status` records uploaded/transcribed/failed |
| T-05-11 | Injection | transcript rendering | mitigate | Transcripts render as React text nodes; no `dangerouslySetInnerHTML` |

No high severity threat is left unmitigated.

**Schema push:** Not required unless Task 1/2 discovers a missing column and adds a migration. If a migration is added, insert a blocking `supabase db push` task before verification.
</threat_model>
