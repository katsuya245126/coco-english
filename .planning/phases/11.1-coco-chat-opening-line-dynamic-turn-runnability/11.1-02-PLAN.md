<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| teacher form -> create/update action | Client-supplied mode, opener, target pattern, and turn JSON cross to server validation |
| mission row/templates -> immutable assignment snapshot | Saved teacher content becomes child-visible homework content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11.1-06 | Tampering | empty/malformed chat opener | mitigate | Server-owned form schema and mirrored snapshot schema require a complete turn 1; browser validation is not trusted |
| T-11.1-07 | Tampering | fabricated target/hints | mitigate | `buildChatOpeningTurn` derives targetExample and every hint transparently from the actual targetPattern; no synthetic answer is labeled teacher-authored |
| T-11.1-08 | Elevation of Privilege | teacher edits another teacher's mission | mitigate | Existing authenticated ownership-scoped create/update service remains the only persistence path; this plan adds no direct DB write |
| T-11.1-09 | Information Disclosure | unreviewed opener reaches a child | mitigate | Generate action is draft-only; D-03 save requires a teacher-reviewed field; snapshot assignment validates the same invariant |
| T-11.1-10 | Tampering | preset mission regression | mitigate | Chat-specific branches/refines leave preset serialization and exact-count validation unchanged; focused regressions cover both modes |
| T-11.1-SC | Tampering | npm/pip/cargo installs | mitigate | No package or install task |
</threat_model>
