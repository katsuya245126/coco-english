<objective>
Deliver the mission-flow UI vertical slice that, on top of plan 03's actions, lets a student walk a full turn end-to-end: the SSR route loads and parses the snapshot + existing attempt behind the unlock gate and resolves the Coco character profile; the client `MissionFlowShell` runs a `useState` step machine (question -> repeat -> transition) showing exactly one card at a time; the buddy asks the snapshot prompt, the student types an answer, the improved target-form sentence (snapshot `targetExample`) appears, the student types the required repeat, and progressive hints reveal in order. Deterministic completion + resume notice wiring + the back-to-home completion screen land in plan 05; this plan delivers everything up to "one full turn works".

Purpose: This is the user-facing slice that makes FLOW-02/04/05/07 demonstrable — after it, a student can do a complete turn (ask -> answer -> better sentence -> repeat) with hints, on a phone, with no chat surface (AI-06 structural). It is the thinnest end-to-end turn that exercises plan 03's service.
Output: mission route `page.tsx`, `MissionFlowShell.tsx`, `StepBuddyQuestion.tsx`, `StepImprovedRepeat.tsx`, `HintRevealer.tsx`, `TurnProgressBar.tsx`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> SSR mission route | Identity from the unlock cookie only; `assignmentStudentId` from the URL must be ownership-checked before any data is returned |
| typed student answer -> rendered DOM | Student-supplied text is displayed back (read-only "Your answer:") — an XSS surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-12 | Elevation of Privilege | mission route serving another student's assignment | mitigate | SSR ownership read filters `id` AND `student_id = unlock.studentId`; missing -> redirect home (V4) |
| T-04-13 | Cross-site Scripting | typed answer / repeat rendered back to the DOM | mitigate | All student text rendered as React text nodes; grep gate forbids `dangerouslySetInnerHTML` in the step components (V5) |
| T-04-01 | Tampering | AI-06 erosion via a buddy-response endpoint | mitigate | Buddy/sentence text comes only from snapshot + static profile; no component imports an AI client; `ai-boundary.test.ts` covers the new component dir (D-09) |
| T-04-14 | Tampering | hint UI used to bypass required repeat | mitigate | Hints are record-only; the shell advances only on accepted answer+repeat, never on hintLevel (D-08) |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan (RESEARCH Package Legitimacy Audit: zero new packages) |

No `high` threat is left unmitigated.

**Schema push:** Not required. This plan adds UI + an SSR read only; no `supabase/migrations/*.sql` file.
