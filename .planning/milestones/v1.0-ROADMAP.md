## Overview

Delivered the teacher-linked speaking-homework loop as a vertical MVP: a teacher sets up a
class, assigns a mission (manually or AI-generated), students complete guided voice practice
with the supportive buddy Coco, and the teacher verifies completion through transcript-first
evidence and exception buckets. Build order reduced the biggest risks first: child-data
privacy, classroom identity, deterministic workflow state, mobile audio, bounded AI behavior,
and fast teacher review.

## Milestone Summary

**Decimal Phases:** None — all 7 phases were planned milestone work.

**Key Decisions:**

- Build teacher-linked speaking homework first (validated — full v1 loop shipped Phases 1-7).
- One recurring supportive buddy (Coco) with `characterId` kept replaceable for later cast (Phase 4).
- Teacher email/password login; students use class code/QR + remembered class + name + 4-digit PIN (Phase 2).
- Store transcripts + short per-turn audio clips, private by default with signed on-demand playback (Phase 5).
- Completion/review states instead of numerical grades (Phase 7).
- Guided missions over open-ended free chat to reduce AI drift (Phase 6, AI-06).
- Server-owned, audited assignment status transitions (Phase 1).
- Name product + buddy "Coco" / full name "Coco English" (2026-06-25).
- Past-due assignments show a "Late" badge and stay launchable; teacher-reopened attempts show a distinct "Retry" badge (Phase 7 live UAT).
