# Friendly PR Template

Keep the existing four headings, but replace technical instructions and checklists with friendly sentence starters:

- **Summary:** “This PR makes it easier to…” and “I made this change because…”
- **How I tested:** “I checked it by…”
- **Screenshots:** “Here’s what it looks like before and after:”
- **Notes for review:** “One thing to know while reviewing this is…”

Only `.github/pull_request_template.md` changes. The result is complete when the template uses these prompts and remains valid Markdown.
