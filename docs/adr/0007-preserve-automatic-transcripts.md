# Preserve Automatic Transcripts When Teachers Clarify Intended Wording

An automatic transcript remains the original speech evidence and is never overwritten. A teacher may save separate teacher-confirmed wording for an owned audio clip; Coco uses it only to replace that clip's derived pronunciation result, without changing mission evaluation, completion, or the automatic transcript. This preserves provenance while giving pronunciation assessment a more accurate reference, and keeps one current derived result rather than adding unused score-version history.
